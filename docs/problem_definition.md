# v0 (오전)

## 1. 이 데이터를 고른 이유

① 내 전공·연구 경험과 연결되는 바이오 데이터이고,
② binding affinity라는 연속형 값을 이용해 회귀분석을 연습할 수 있으며,
③ 결측치·이상치부터 EDA와 모델 평가까지 데이터 분석의 전체 과정을 경험할 수 있기 때문에 이 데이터셋을 선택했어.

## 2. 오늘 풀 문제

나는 Binding affinity로 화합물이 단백질에 얼마나 잘 붙는지를 molecular weight, logp, protein_pi 등의 값으로 예측하려고 해.
이게 맞으면 신약 후보를 스크리닝하는 연구원에게 쓸모가 있어.
지금은 그냥 초보자가 실험 전에 컴퓨터로 스크리닝을 목적으로 하는 연구원 정도면 성공이라고 생각해.

## 3. 확인해 볼 것 3가지

1. 가장 Binding affinity가 높은 것은 무엇인지
2. Molecular weight이 어떤 영향을 미치는지
3. Protein_pi가 결합력과 어떤 상관관계를 가지는지
